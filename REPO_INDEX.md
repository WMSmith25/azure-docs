## Key Documentation Patterns

### Landing Pages
Each service typically has an `index.yml` landing page that serves as the hub for that service's documentation. These use the `YamlMime:Landing` format and include:
- Service overview and description
- Quick start guides
- Tutorials
- Common tasks
- Related services

### Article Structure
Most service areas follow this structure:
```
articles/<service-name>/
├── index.yml                    # Landing page
├── overview.md or quickstart.md # Getting started content
├── how-to-*.md                  # How-to guides
├── tutorial-*.md                # Step-by-step tutorials
├── concept-*.md                 # Conceptual content
├── troubleshoot-*.md            # Troubleshooting guides
└── toc.yml                      # Table of contents
```

### Includes Directory
The `includes/` directory contains reusable content snippets that can be referenced across multiple articles using:
```markdown
[!INCLUDE [include-file-name](../includes/include-file-name.md)]
```
